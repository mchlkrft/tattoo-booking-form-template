# Guest Spot Request Template

A reusable Markdown template for tattoo guest spot booking requests. Designed for traveling tattoo artists who need to capture city and date context up front. Copy into your form builder, internal CRM, or Notion page.

This template adds guest spot specific fields on top of the normal tattoo intake. Pair it with the [tattoo client intake template](tattoo-client-intake-template.md) when you need the full booking flow.
