# Cover-Up Tattoo Request Template

A reusable Markdown template for cover-up tattoo requests. Designed for clients submitting an existing tattoo that they want covered or worked over. Cover-ups need more upfront information than a standard request: the size, age, ink saturation, and skin condition of the existing piece all change what is possible. Copy into your form builder, internal CRM, or Notion page.

This template focuses on cover-ups only. Pair it with the [tattoo client intake template](tattoo-client-intake-template.md) for the normal request flow, or use it on its own when you only accept cover-up consultations.
