# Tattoo Waitlist Reopening Message Templates

Intended reader: tattoo artists reopening a defined booking window to people already on a waitlist.

The [tattoo waitlist guide](../docs/tattoo-waitlist-guide.md) owns the setup and management of the list. This copy pack starts when you are ready to reopen. It gives you the waitlist-specific messages for early access, reminders, request receipt, and closing the round without treating waitlist interest as a guaranteed booking.

Replace every `___` placeholder, use your real dates, and link the same full tattoo request form throughout.

## Decide the reopening details first

Before sending any message, write down:

- City or studio
- Appointment date range
- Types and sizes of projects you want for this round
- How much work can realistically fit
- Waitlist invitation date
- Full request deadline
- Decision date
- Public opening date, if there will be one
- Deposit deadline for approved requests

Clean obvious duplicates, people who already booked, and anyone who asked to leave. If capacity is tight, invite a useful group based on the correct city, timing, and project fit. Say clearly that the waitlist offers early access to request, not a strict queue and not an appointment.

## Early-access invitation

```text
Subject: Early booking access for ___

Hey ___,

You joined my waitlist for ___, and I am opening requests for appointments
between ___ and ___.

If you still want to be considered, send the full tattoo request here by ___:
___

Please include the idea, placement, rough size, references, and the dates that
work for you. Joining the waitlist or sending a request does not guarantee an
appointment. I review each project before offering a date.

I expect to send decisions by ___. No payment is needed unless I approve the
request and send the deposit step.
```

## Short early-access version

```text
My books are reopening for ___, and the waitlist gets the link first.

Send the full tattoo request by ___: ___

This is early access to request, not a confirmed appointment. I will review the
projects and reply by ___.
```

## Deadline reminder

Send one reminder only when it is useful. Use the real deadline instead of fake urgency.

```text
Quick reminder: early booking access for ___ closes on ___. If you want your
project considered for this round, send the full request here: ___

If the timing no longer works, you do not need to do anything. You can stay on
the waitlist for a future opening unless you unsubscribe.
```

## Request received

```text
Hey ___, I received your full request for ___. I will review the idea,
placement, size, references, timing, and fit before I offer any date.

You can expect a decision by ___. The request is not a confirmed appointment
and no payment is needed yet.
```

Do not use this message if you already know the request is incomplete. Ask for the one or two details that block a real decision instead.

## Decision replies and public opening

Once a full request has been reviewed, use the [tattoo booking reply templates](../docs/tattoo-booking-reply-templates.md) for approval, deposit, confirmation, waitlist, and decline messages. Those decisions mean the same thing whether the request came from a waitlist or a public form, so their wording has one home.

If suitable waitlist requests do not fill the real capacity, use the [books-open and books-closed announcement templates](books-open-announcement-templates.md) for the public opening. Name any limits that remain instead of presenting a few leftover session blocks as a wide-open calendar.

## Round closed message

```text
Requests for ___ are now closed. Thanks to everyone who sent a project.

If you submitted a full request, you should receive a decision by ___. If you
are still on the waitlist but did not submit this round, your current status is
___. You can update or leave the list here: ___.

The next opening is ___ / not scheduled yet.
```

Silence makes an organized waitlist feel like another lost inbox. Close the round even when the next date is unknown.

## Status words to keep consistent

| Status | Meaning |
|---|---|
| Waitlisted | Interested, but not invited for this round yet |
| Invited | Received early access to submit a full request |
| Requested | Sent the tattoo details for review |
| Approved | The project fits and can move to dates and deposit |
| Confirmed | The required confirmation step is complete |
| Passed | Not booked in this round |
| Removed | Booked elsewhere, unsubscribed, or no longer relevant |

Do not use "booked" for someone who joined the list, received an invitation, or submitted a request.

## Reopening message checklist

- [ ] City, appointment window, project fit, and capacity are defined
- [ ] Duplicate, converted, and removed entries are cleaned up
- [ ] Early access is described as a request opportunity, not a booking
- [ ] Every message uses the same full request link
- [ ] Request and decision deadlines are specific
- [ ] No deposit is requested before the project is approved
- [ ] Approved and confirmed are treated as different states
- [ ] Suitable overflow is handled honestly
- [ ] Public opening happens only if capacity remains
- [ ] The round ends with a clear status or next step

If you want closed-books interest connected to the next request round, [Inklee's tattoo artist waitlist](https://inklee.app/tattoo-artist-waitlist) is built for that handoff.
