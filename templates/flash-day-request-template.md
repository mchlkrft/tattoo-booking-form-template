# Flash Day Request Template

A reusable Markdown template for tattoo flash day booking requests. Flash days work differently from custom intake: the design is already drawn, the artist needs to assign each design to a client, and time slots are usually pre-defined. This template captures the request without the open-ended custom design flow.
