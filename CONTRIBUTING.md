# Contributing

Thanks for wanting to improve this repo. It is a free, tool-neutral set of tattoo booking templates and guides, and it gets better when working artists correct it and translate it. Contributions are welcome, and you never have to contribute in order to use anything here: the MIT license already covers that.

## What is welcome

- Corrections: a field that does not match how tattoo booking actually works, a broken link, an unclear sentence.
- Translations: any template or guide, in any language. This is the most useful contribution of all, because the templates are meant to be copied into real forms.
- New templates or examples: a request template for a situation the repo does not cover yet, or a worked example that adds genuine variety.
- Improvements: a clearer explanation, a better checklist, a field worth adding.

## What is out of scope

- Product marketing, or comparisons that push one specific tool. The repo stays tool-neutral, and the templates work with any form builder.
- Keyword-stuffed copy written for search engines rather than for a person reading it.
- Legal or medical claims. These are workflow templates, not legal or health advice, and they should not pretend otherwise.

## Voice and format

Keep new content in the same shape as what is already here:

- Plain, direct prose. Write for a working tattoo artist, not for a search crawler.
- No em dashes. Use a period, comma, colon, or parentheses instead.
- Sentence case for headings. Title case only in the H1.
- Straight quotes and plain text. No smart quotes, no invisible characters.
- Use `___` for blanks a client fills in, and `[ ]` for checkboxes.
- Use relative links between files, and end every file with a `## Related` list.
- Templates are a short intro, the form itself, and a brief "why" or "how to use" section. Guides open on the problem, get to the substance quickly, and include a checklist where it helps.

If in doubt, open an existing guide and match it.

## How to contribute

1. Fork the repo and make your change on a branch.
2. Keep each pull request focused on one thing: one translation, one new template, one set of corrections.
3. Check that your links resolve and that your file ends with a `## Related` section.
4. Open a pull request describing what you changed and why.

For a translation, add the translated file next to the original with a clear language suffix, for example `tattoo-deposit-policy-template.de.md`, and link it from the original file's `## Related` section so people can find it.
